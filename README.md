# Vyapar : DigiKhata
A digital bookkeeping and ledger solution transforming traditional Bahi Khata for small rural and urban merchants, built for LJ Innovation Village.

Core Features:
=> Digital Ledger: Instant credit/debit tracking.
=> Smart Reminders: WhatsApp/SMS notifications for pending payments.
=> Digital Invoicing: Quick receipt generation.
=> Analytics Dashboard: Simple sales and profit overviews.
